ESTATEFLOW BROWSER READY
This is a self-contained browser demo. No Node, npm or Supabase is required.

OPTION 1: Double-click index.html.

OPTION 2: In Terminal, open this folder and run:
python3 -m http.server 8080
Then open http://localhost:8080

The demo has Dashboard, Properties, Leads and Settings. Data is in memory and resets on refresh.
For persistent production data, use the full Expo/Supabase project.
